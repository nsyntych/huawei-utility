About Huawei Utility

This is a browser-based utility suite for Huawei routers and CPE devices, forked and expanded from the original project created by André Brandão (Fayaru / @andreluis034).

All computations, AES-256-CBC decryption, and PBKDF2/MD5/SHA256 password generation execute directly in your browser client. No files, passwords, or router data are ever sent over the network.

XML Config Decryptor: Upload backup configurations (hw_ctree.xml) to decrypt all hidden credentials, including factory passwords (e.g. admin), Wi-Fi PSK keys, and CLI user passwords.
Password Generator: Compute hashes matching Huawei router firmware modes (MD5, SHA256-MD5, PBKDF2-SHA256 with 5000 iterations).
Cipher / Decipher: Manually cipher or decipher individual strings formatted with Huawei's custom base-93/AES-CBC encoding ($2...$).
Original Author & Research: André Brandão (Fayaru)
